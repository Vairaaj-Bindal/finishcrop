The Math

Built on peer-reviewed
agronomic science.

FAO-56 Penman-Monteith (ET₀)
ET₀ = (0.408·Δ·Rn + γ·(900/T+273)·u₂·vpd) / (Δ + γ·(1 + 0.34·u₂))

Reference evapotranspiration (mm/day). Δ = slope of saturation vapor pressure curve; γ = psychrometric constant; Rn = net radiation; u₂ = wind speed at 2m; vpd = vapor pressure deficit. Drives all water requirement predictions.

Crop Water Requirement
NIR = ET₀ · Kc · D − Pe(R)

Net Irrigation Requirement (mm/season). Kc = FAO crop coefficient; D = growing days; Pe(R) = effective rainfall using USDA formula: Pe = R·(125−0.2R)/125 for R ≤ 250mm, else Pe = 125+0.1R.

Multi-Task Uncertainty Loss (Kendall 2018)
ℒ = Σᵢ [ exp(−sᵢ)·ℒᵢ + sᵢ ] where sᵢ = log σᵢ²

Automatic task weight balancing via learned log-variance parameters s_crop, s_fert, s_water. Enables joint training of classification and regression heads without manual tuning of loss weights.

Focal Loss (Lin et al. 2017)
FL(pₜ) = −α·(1−pₜ)^γ·log(pₜ)

Handles extreme class imbalance across 1,920 crop varieties. γ=2.0, α=0.25. Down-weights easy examples so the model focuses on rare or difficult-to-distinguish crop species.

MoE Routing
P(eᵢ|x) = softmax(Wg·x)ᵢ → top-2 gates

Mixture of Experts gating: 4 specialized expert FFNs, each handling related crop families (e.g., tropical fruits, cereals, legumes, brassicas). Auxiliary load-balancing loss ensures uniform expert utilization.

Nutrient Balance Score
NBS = (N/N̄ · P/P̄ · K/K̄)^⅓

Geometric mean of normalized NPK values. Values close to 1.0 indicate balanced nutrition. Drives fertilizer recommendation: Urea when N-deficient, DAP/SSP for P, MOP/K₂SO₄ for K, Compost for balanced organic profiles.
